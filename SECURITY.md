# Security policy

If you find a problem in this kit that could make a site less safe (for example a generated policy that allows something it shouldn't, or a checker that misses a dangerous setting), please report it privately through GitHub: **Security → Report a vulnerability** on this repository. Please don't open a public issue for it.

Please include the command or options you used, the output, and what you expected. We aim to reply within a week.

Outdated service domains (a vendor changed the hosts it loads from) are not security issues; open a normal issue or pull request for those.
